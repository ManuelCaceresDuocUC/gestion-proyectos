# Guion de demo

Completar en el issue C-16. Duración objetivo: la que indique el profesor (ensayar con cronómetro).

1. Reiniciar: `scripts/reset-demo.sh` y entrar como ADMIN.
2. Presentar el caso (proyecto, EDT, Gantt, recursos, hitos, KPI, solicitudes, tableros).
3. **Recálculo 1:** cambiar una duración -> mostrar Gantt, costos, KPI y tableros antes/después y explicar el efecto.
4. **Recálculo 2:** modificar recursos -> costo, sobreasignación, KPI.
5. **Recálculo 3:** aprobar una solicitud -> se aplica al plan; línea base intacta; KPI de cambio.
6. Mostrar el rol USUARIO_PROYECTO (puede trabajar el proyecto, pero no administrar usuarios ni KPI).

Quién habla en cada parte: A (planificación y Gantt), B (recursos y KPI), C (cambio y tableros).
